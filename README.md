# FocusLock

Windows 熬夜锁屏工具。到点盖住屏幕，让你早点睡。

## 原理

维护一个「锁机时间区间」集合，轮询检查当前时间是否与任一区间有交集——有交集就进锁，没交集就出锁。解锁就是把区间删掉或标记作废，轮询自然找不到。

没有驱动，没有服务，没有防破解。就是一个 PowerShell 脚本加一个计划任务。

## 部署

```cmd
git clone https://github.com/Zykalai/focus-lock.git
cd focus-lock
install.cmd
```

双击 `install.cmd`，它会复制文件到 `%LOCALAPPDATA%\FocusLock`、注册计划任务、设置开机自启。不需要管理员权限。

卸载：`uninstall.cmd`

## 用法

| 文件 | 作用 |
| --- | --- |
| `lock.cmd` | 弹窗选时长后上锁 |
| `lock.cmd 30` | 锁 30 分钟 |
| `unlock.cmd` | 解锁 |
| `settings.cmd` | 设置时段和周几 |

## 两种锁

- **熬夜锁** — 按设定的时段每天自动触发，比如 00:00-06:00、跳过周六
- **立刻锁** — 双击 `lock.cmd`，弹窗选多久（15/30/60/120 或自定义），往集合里加一条 `[现在, 现在+N分钟]`

## 三种解锁

1. 等它自己结束（锁屏上有倒计时）
2. 输完 1000 位数字（100 组，每组 10 位）
3. 双击 `unlock.cmd`

定时锁解锁 = 删掉那条区间。熬夜锁解锁 = 把今天这份的 key 标记作废，明天新的照常锁。

## 区间重叠

定时锁和熬夜锁可能同时覆盖当前时刻：

- 锁屏显示**最晚结束**的那个
- 只要两者有交集，在并集内任何时刻解锁都**同时解除两个**
- 不相交时各解除各的

```
熬夜 22:00-02:00 + 定时 01:00-04:00（重叠，并集 22:00-04:00）
  23:00 解锁 → 两个都解除
  03:30 解锁 → 两个都解除

熬夜 22:00-02:00 + 定时 05:00-06:00（不重叠）
  23:00 解锁 → 只解除熬夜
  05:30 解锁 → 只解除定时
```

## 锁屏界面

深色全屏，中间是时钟和倒计时，两个按钮：

- **打开豆包** — 锁定期间唯一放行的应用
- **立刻关机** — `shutdown /s /t 0 /f`，未保存的文档会丢

关机时遮罩主动让路，开机后如果还在时段内 1 秒内重新盖上。

## 占用

| | 数值 |
| --- | --- |
| 锁屏期间内存 | ~250 MB（PowerShell 基础开销） |
| 不锁时 | 0 进程 0 内存 |
| 后台轮询 | 每 60 秒一次，进入窗口前精确 sleep 到边界 |

不联网，不写 HKLM，不装服务/驱动，不改系统文件，不碰电源计划。

## 已知限制

- 计划任务最小重复间隔 1 分钟，边界在 90 秒外的时段靠下一次 tick 接手
- 非管理员账户下，任务管理器拦截靠杀进程实现（写不了 `DisableTaskMgr` 策略）
- 没有防破解，`unlock.cmd` 双击即解锁，这是有意为之
