# FocusLock

Windows 熬夜锁屏工具。到点盖住屏幕，让你早点睡。

## 一句话原理

维护一个「锁机时间区间」集合，轮询检查**当前时间是否与任一区间有交集**——有交集就进锁，没交集就出锁。解锁就是把区间删掉或标记作废，轮询自然找不到。

## 换电脑部署

```cmd
git clone https://github.com/你的用户名/focus-lock.git
cd focus-lock
install.cmd
```

双击 `install.cmd` 即可，它会：

1. 把文件复制到 `%LOCALAPPDATA%\FocusLock`
2. 注册计划任务 `FocusLockGuard`（每 60 秒轮询）
3. 设置开机自启

**不需要 exe，不需要管理员权限。** PowerShell 5.1 是 Windows 自带的。

卸载：双击 `uninstall.cmd`。

## 日常使用

| 文件 | 作用 |
| --- | --- |
| `lock.cmd` | 立刻上锁 |
| `lock.cmd 30` | 锁 30 分钟 |
| `unlock.cmd` | 解锁 |
| `settings.cmd` | 设置熬夜锁时段和周几 |

## 两种锁

**熬夜锁** — 按 `settings.cmd` 里设的时段每天自动触发。

**立刻锁** — 双击 `lock.cmd`，往区间集合里加一条绝对区间 `[现在, 现在+N分钟]`。

## 三种解锁

1. **等它自己结束** — 锁屏上有倒计时
2. **输完 1000 位数字** — 100 组，每组 10 位
3. **双击 `unlock.cmd`** — 立刻解除

三条路走的是同一套逻辑：

- **定时锁** → 删掉 `manual.json` 里那条区间
- **熬夜锁** → 把「今天这一份」的 key 写进 `state.json` 的 `dismissed`，明天生成新 key 照常锁

## 两个区间重叠时

定时锁和熬夜锁可能同时覆盖当前时刻。行为：

**锁定时间显示最晚结束的那个**

```
熬夜 22:00-02:00 + 定时 01:00-04:00
→ 锁屏倒计时显示到 04:00（两者并集的终点）
```

**只要两个区间有交集，在并集内任何时刻解锁都同时解除两个**

```
并集 22:00-04:00

23:00 解锁  → 定时 + 熬夜 都解除
01:30 解锁  → 定时 + 熬夜 都解除
03:30 解锁  → 定时 + 熬夜 都解除
```

不相交时各解除各的：

```
熬夜 22:00-02:00 + 定时 05:00-06:00（中间有 3 小时空隙）

23:00 解锁  → 只解除熬夜
05:30 解锁  → 只解除定时
```

## 配置

`%LOCALAPPDATA%\FocusLock\config.json`

```json
{
  "autoEnabled": true,
  "window": {
    "start": "00:00",
    "end": "06:00",
    "skipDays": [6]
  }
}
```

`skipDays` 是 ISO 周几（1=周一 … 7=周日），列在这里的那天不锁。

改配置用 `settings.cmd`，改完立即生效。

| 文件 | 内容 |

## 它不做什么

- 不联网
- 不写 HKLM
- 不装服务、不装驱动
- 不改系统文件、不改权限
- 不碰电源计划、频率、散热
- 锁屏期间约 250 MB 内存（PowerShell 基础开销），不锁时 0 进程 0 内存
- 后台轮询每 60 秒一次，进入窗口前会精确 sleep 到边界

## 已知限制

- 计划任务最小重复间隔是 1 分钟，所以边界在 90 秒外的时段靠下一分钟的 tick 接手
- 任务管理器拦截在非管理员账户下靠杀进程实现（写不了 DisableTaskMgr 策略）
- 没有防破解设计，`unlock.cmd` 双击即解锁，这是有意为之

## 锁机期间能干嘛

- 打开豆包（唯一白名单）
- 立刻关机（`shutdown /s /t 0 /f`，未保存的文档会丢）

关机时遮罩主动让路，开机后如果还在时段内 1 秒内重新盖上。
